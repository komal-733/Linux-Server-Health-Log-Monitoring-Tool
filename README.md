# Linux Server Health & Log Monitoring Tool

Purpose : practice linux

step1 - create the project (mkdir,mkdir -p,cd)

step2 - create application logs (touch,vim,cat)

step3 - investigate logs (grep,grep -n,grep -i,grep -c,tail,tail -n 3,|)

step4 - Create a Configuration File (touch,vim,esc:wq,cat)

step5 - File Permissions (ls,ls -la,chmod,sudo,chown,ssh-keygen -t ed25519 -C "gmail",ssh -T)

step6 - CPU & Memory Monitoring (lscpu,top,free -h,vmstat)

step7 - Disk Monitoring (df -h,du -h --maxdepth=1 /,du -sh ., sudo find / -type f -size =100M 2>/dev/null)

step8 - Process Investigation (ps aux,sudo apt install htop,htop,ps aux --sort=-%cpu | head,ps aux --sort=-%mem | head,ps aux | wc -l,ps aux | grep -i zombie)
